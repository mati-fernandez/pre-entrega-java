# Pre-Delivery Project - Java CLI

## Description
Command-Line Interface (CLI) application for Article and Category management. Developed as a pre-delivery project for the "Backend con Java" course at Talento Tech. 

This version runs entirely via terminal, establishing the logical and data model foundations before the web migration.

## Features
* Full CRUD for Articles and Categories.
* Object-Oriented Programming (OOP) architecture.
* Implementation of Inheritance, Polymorphism (e.g., Electronic vs. Grocery Articles), and Abstract Interfaces.
* Centralized input data validations (length, null values, negative values).
* Temporary in-memory storage using Generic Repositories.

## Technologies
* Java (Core)
* CLI (Terminal)

## Usage
1. Clone the `pre-entrega-java` repository.
2. Compile the files or open the project in an IDE.
3. Run the `Main` class to start the interactive console menu.
